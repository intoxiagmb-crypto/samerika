IMPLEMENTED CHANGES
1. Native startup: embed the existing 1,406-byte JavaScript integration bridge into the DEX at build time. Removes startup asset I/O, temporary input buffer and duplicate packaged bridge asset. Bridge contents/behavior are preserved.
2. Cookie persistence: run the same flush operation on a serial background executor instead of blocking onPageFinished/onPause on the main UI thread. Cookie access policies, HTTPS-only navigation, HttpOnly sessions and certificate validation remain intact.
3. CSV exports: move JSON/base64 processing off the UI thread; serialize export work and reject overlapping exports while decode/save is in progress. Enforce the existing 8 MB limit on the native side as well. Keep Android's document picker and save behavior.
4. WebView lifecycle: track/dispose temporary popup WebViews, detach views before destruction, clear upload/export references and shut down the export worker. Handle renderer termination using the existing error/retry screen instead of the platform's default host-process failure behavior. Guard delayed print/page callbacks against a destroyed view. These are code-level fixes; device memory/crash rates were not measured.
5. APK bottom navigation: use client-side route transitions rather than a full document reload when leaving the workspace. Clicking Profile resets workspace state using the existing history restoration path; busy writes still prevent navigation. No menu labels/layout changes.
6. Dashboard rendering: reuse currency/date formatters rather than constructing Intl formatters for each table cell. Keep locale, output and invalid-date handling.
7. Snapshot CPU: group projects by lead before applying the unchanged access predicate. Project-dependent roles avoid repeated whole-project scans. Deleted project history remains available to the policy; full output parity was checked for eight roles across Active/Pending/Suspended statuses. Roles resolved from lead fields alone keep their original fast path.
8. Database read paths: migration 0007 adds notifications(user_id, created_at) and projects(lead_id) indexes. The notification feed no longer needs a full scan plus temporary sort; the project lookup index also covers deleted history, which the existing partial unique index does not. No record/schema-column changes or permission changes.
9. Regression test repair: the three pre-existing file-preview test failures used the obsolete getPortalIdentity mock. They now mock the actual getPortalUser dependency, retaining real role/access checks. This was a test harness defect, not an observed production login defect.

DECISIONS / LIMITS
WebView's HTTP cache and Next image/static-asset optimization remain in use. No cache-first override, shared authenticated response cache, offline business writes, weakened password hashing or artificial loading delay was introduced. Auth/private documents retain no-store and server authorization. Existing asynchronous login hashing, database read batching, lazy quotation editor and hidden-page banner suspension were already present.
No image/branding/layout redesign, extra native dependencies, largeHeap, forced garbage collection or animation removal. D8 release mode retained: the native APK is already about 25 KB with no third-party runtime libraries; adding R8 rules without device coverage for negligible size gain was not justified. The shell still needs a network connection; these changes do not remove server/network latency.
